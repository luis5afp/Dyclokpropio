# MP4 to Y4M Converter Chrome Extension

这是一个Chrome扩展插件，用于将MP4视频文件转换为Y4M格式，配合Chrome的`--use-file-for-fake-video-capture`参数使用。

## 功能特点

- 🎯 **一键转换**：点击插件图标直接选择文件并转换
- 🔄 **状态反馈**：图标会显示loading状态，转换完成后恢复
- 📊 **智能检测**：自动检测视频尺寸和参数
- 🌍 **环境感知**：自动获取环境信息
- 📝 **详细日志**：所有操作信息都会输出到控制台

## 使用方法

1. **安装插件**：将插件文件夹加载到Chrome扩展程序中
2. **启动桌面应用**：确保DICloak桌面应用正在运行
3. **点击图标**：直接点击浏览器工具栏中的插件图标
4. **选择文件**：在弹出的文件选择器中选择MP4文件
5. **等待转换**：插件图标会显示loading状态，转换完成后恢复

## 工作流程

```
用户点击图标 → 获取环境信息 → 调用桌面应用API → 弹出文件选择器 → 转换MP4为Y4M → 显示结果通知
```

## 技术细节

### 图标状态

- **正常状态**：摄像头图标，提示"点击选择MP4文件并转换为Y4M"
- **Loading状态**：loading图标，提示"正在选择文件并转换..."

### 环境信息获取

插件会自动获取以下信息：

- 当前页面URL和域名
- 环境ID和端口号
- 时间戳等元数据

### API调用

- **端点**：`http://127.0.0.1:{port}/dic_api/video/select-and-convert`
- **方法**：POST
- **参数**：环境信息 + 转换选项

### 转换选项

- **质量**：slow（高质量）
- **尺寸检测**：自动检测原始视频尺寸
- **输出路径**：自动生成到环境目录

## 调试信息

所有操作信息都会输出到浏览器控制台，包括：

- 🌍 环境信息获取和解析
- 🔄 API调用过程和结果
- 📊 视频信息和转换参数
- ✅ 转换成功信息
- ❌ 错误信息和故障排除

## 注意事项

1. **桌面应用依赖**：插件需要DICloak桌面应用运行才能工作
2. **端口配置**：默认端口27777，会从环境参数中自动获取
3. **文件格式**：仅支持MP4格式输入，输出Y4M格式
4. **权限要求**：需要storage、tabs、activeTab、notifications权限

## 故障排除

- **点击无反应**：检查桌面应用是否运行
- **文件选择失败**：检查文件路径和权限
- **转换失败**：查看控制台错误信息
- **环境信息错误**：检查当前页面URL参数
