Operación → Abrir · Perfil de pruebas · Almacén

Al pulsar Abrir, se inicia una captura temporal de metadatos antes de solicitar la apertura. El panel puede abrirse después; conserva los eventos de esa operación. Si se configura aparte, pueden observarse documentos de un servidor de pruebas autorizado. El ID de fila todavía no verifica la identidad de Chromium. No captura todo el tráfico de red ni muestra cookies, contraseñas, tokens, cabeceras o cuerpos privados. El diagnóstico de apertura funciona sin clave Open API.
