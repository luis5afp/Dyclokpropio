diloakPRO · Diagnóstico de comunicación

Operación → Abrir · Diagnóstico en vivo · Sin archivo automático

Al pulsar Abrir, se inicia una captura temporal de metadatos antes de solicitar la apertura. El panel puede abrirse después; conserva los eventos de esa operación. Si se configura aparte, pueden observarse documentos de un servidor de pruebas autorizado. El ID de fila todavía no verifica la identidad de Chromium. No captura todo el tráfico de red ni muestra valores de cookies, contraseñas, tokens, cabeceras o cuerpos privados. Solo indica la presencia de algunas cabeceras sensibles y contabiliza bytes sin leer su contenido. El diagnóstico de apertura funciona sin clave Open API. No se archiva automáticamente; solo se guardan JSON y TXT cuando el usuario pulsa Exportar. Se conservan metadatos en memoria durante esta sesión.

Estado de configuración y comunicación (verificación parcial)

El diagnóstico registra si una etapa se ejecutó, no si se restauraron las contraseñas, cookies o credenciales de proxy. Nunca registra estos valores.

Auditoría de apertura completa (cobertura parcial)

Se registran desde Abrir hasta el fin del observador las etapas, solicitudes/respuestas de Electron y procesos/conexiones muestreados. No se leen contraseñas, tokens, valores de cookies, códigos 2FA ni cuerpos de solicitudes/respuestas. Una etapa completada no demuestra que Chromium haya aplicado una configuración.

Tráfico en vivo — HTTP(S), Node fetch y conexión TCP/TLS

Los bytes de salida son cuerpo entregado a la solicitud para envío; los de entrada son cuerpo observado por el cliente. No incluyen todo el tráfico de Chromium ni prueban por sí solos cuántos bytes llegaron al servidor. «Presente» no confirma que el servidor haya aceptado una cookie o credencial.

Cómo pasan las cookies a Chromium

El motor puede restaurar cookies desde los datos del perfil, recibir una cabecera Set-Cookie en una respuesta o crearlas mediante JavaScript o APIs del navegador. Este diagnóstico confirma etapas de preparación y presencia de Set-Cookie en solicitudes Node observadas, pero no comprueba que Chromium las haya instalado. No inspecciona la base de cookies ni guarda sus valores.
