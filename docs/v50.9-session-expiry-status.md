# DyclokPRO 50.9 — parche candidato para expiración de sesión

Estado: **corrección de código preparada, SIN instalador compilado, SIN pruebas de inicio de sesión en Windows y SIN publicación de Release**.

Este trabajo se basa en el instalador `DyclokPRO_50.8_win_x64.exe` proporcionado por el usuario, no en la base 3.0.0 que contiene la rama `main` de este repositorio. No apliques este parche a los bundles de `main`.

## Alcance

- Detecta fechas de expiración expresadas en segundos (rangos de época UNIX) y las normaliza a milisegundos, manteniendo la expiración real.
- Corrige la comparación con `Date.now()` y la escritura de `TOKEN_STATE` en los bundles extraídos.
- Recalcula las entradas de integridad SHA-256 de `app.asar` para los dos archivos desempaquetados.
- **No modifica cuentas, contraseñas, cookies ni perfiles personales**.

## Qué falta antes de publicar v50.9

1. Disponer de un proceso de construcción y firma NSIS reproducible que empaquete la aplicación 50.8 extraída con estos cambios.
2. Verificar en Windows inicio de sesión, inicio tras reiniciar y cambio entre usuarios con cuentas de prueba (sin publicar sus datos).
3. Confirmar el formato real del campo `expiredTime` en la respuesta del servicio, que puede ser causa **hipotética**, no diagnosticada de manera definitiva.
4. Confirmar que no existe otro cierre de sesión iniciado por eventos de red, API, almacenamiento o cambios de usuario.
5. Publicar un EXE verificable solo cuando esas pruebas terminen satisfactoriamente.

No se debe renombrar el ZIP de parche como instalador ni cambiar el número de versión para aparentar una compilación.
