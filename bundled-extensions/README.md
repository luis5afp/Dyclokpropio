# Extensiones distribuidas con Dyclokpropio

`Cookies-Pro-v16.9.10-runtime.zip` procede de la extension del propietario y
contiene los ocho archivos estrictamente necesarios para MV3. Su SHA-256 es
`053c843178e9401260030c0e0e7f036c9c1cade2a0e92113c7eff4f6426e32d9`.

Tras instalar dependencias, ejecutar `node tools/unpack-bundled-extension.js`.
Esto crea `plugins/.cookies-pro-privada/` antes de construir el instalador.
No contiene cookies de usuario ni otros datos de perfiles.
